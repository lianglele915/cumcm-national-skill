# 用户论文格式：无目录

来源：用户于2026-11-08提供的七张论文格式截图，并明确说“论文格式不要目录那块”。**不生成目录是明确要求**；其余截图内容作为工作排版与写法参考，不冒称当届官方统一规范。图片水印、批注颜色与占位文字不复制。

## 章节与页码

题目→摘要→关键词→一、问题重述→二、问题分析→三、模型假设→四、符号说明→五、模型建立与求解→六、模型评价与优化→参考文献→附录。按实际问题调整数据准备及检验位置，保持编号一致。

摘要、关键词之后直接进入正文，正文通常另起页；不添加目录页、目录标题、Word TOC域、LaTeX的 `\tableofcontents` 或空白占位页。不因示例文字“鼓励使用目录”恢复目录，也不删除实际参考文献和附录。仅用户后续明确改变要求时才加目录；官方冲突须明确告知。

正文页码采用阿拉伯数字，从1连续编号，页脚居中；摘要前置页与正文用合理分节处理，不为了省略目录打乱页码。

## 字体与段落参考

| 元素 | 用户截图参考样式 |
|---|---|
| 论文题目 | 三号黑体，居中 |
| 摘要标题 | 三号黑体加粗，“摘 要”，居中，段前段后约一行 |
| 正文 | 中文宋体小四12pt，英文和数字Times New Roman；单倍行距，首行缩进两字 |
| 一级标题 | 四号黑体，无首行缩进，居中，段前段后6pt，编号“一、”“二、”等 |
| 二级标题 | 小四黑体，顶格左对齐，无首行缩进，段前段后6pt，编号1.1、1.2等 |
| 三级标题 | 小四黑体，顶格左对齐，无首行缩进，段前段后6pt，编号1.1.1等 |
| 关键词 | 摘要后空一行；“关键词：”四号黑体加粗，内容宋体小四，通常3–5个，分号分隔，末尾不加标点 |
| 图表题 | 表题在上、图题在下，居中无首行缩进；中文宋体五号加粗，西文Times New Roman五号加粗 |
| 符号表 | 三线表，列为符号、符号意义、备注/单位；数学变量使用适当斜体，运算符及单位依数学排版规则用正体 |

字体不存在时选择明确的兼容替代并告知；不可仅写入字体名就声称渲染一致。实际版式通过最终DOCX/PDF渲染检查。

## 写法与篇幅参考

- 摘要以约300–600字、一页为写作参考，按背景目标、逐问方法与真实结果、贡献/建议组织；使用纯文字，不塞图表，不以数量目标编造结果。
- 问题重述简洁，优先约10行且不超过一页，保留目标、关键条件和指定输出；原题复杂时完整准确优先。
- 问题分析优先控制一页，逐问说明数学本质、数据特点、选法及理由，必要时配思路图；此处写方法与预期输出，不提前堆砌最终求解数字。
- 模型假设逐条给依据及影响，不能以无证据的“数据无误”逃避质量诊断；符号尽量符合领域惯例并保持全文一致。
- **用户后续明确要求详细写作、最好约30页，已取代截图“20页以内”参考。** 完整论文按摘要至参考文献的实际渲染篇幅规划约30页，遵守已核实的当届页数限制；附录单列。重点增加必要推导、实现说明、结果解释、对比与检验，不靠字号行距、空白、重复内容或长附录补页，细则见 [写作深度](05-writing.md)。

摘要和排版值是用户截图参考；无目录与约30页详细论文是用户的明确偏好，均不宣称为官方通用规则。
